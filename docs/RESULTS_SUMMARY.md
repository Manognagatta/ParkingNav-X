## Important disclaimer

> All experiment results below are derived from **synthetic demand data** generated by a configurable model (hour-of-day arrival curves, weekday/weekend factors, event intensity multipliers). The simulation does not reflect real measured VIT-AP occupancy, gate counts, or travel times. Results demonstrate that the system functions correctly and that ParkingNav-X (strategy P) produces different decisions than the baselines under controlled conditions — they do not prove real-world effectiveness.
>
> **Counterfactual label:** "Simulation-based estimate; not a deployed real-world intervention."

- XGBoost and HistoricalAverage perform comparably because synthetic data has a highly predictable hour/day structure. On real data with more noise, the gap would likely widen.
- Overflow lot R² = 0.37 is expected: low flat occupancy means low variance, making R² a poor discriminator. Absolute MAE (0.041) is still small.
- MovingAverage performs poorly (R² ≈ 0 or negative) because it cannot capture daily patterns — this validates that a pattern-aware model is needed.
- 90% conformal interval coverage is close to target (0.90) for most lots, confirming valid uncertainty quantification.

## Section 3 — Known limitations

| Limitation | Impact | Status |
|-----------|--------|--------|
| All training data is synthetic | Model may learn simulator assumptions; R² will likely be lower on real data | Documented; no real data available before deadline |
| Experiment matrix not yet run | No strategy-comparison evidence available | To be run before review |

| Proactive trigger calibrated on synthetic demand | May fire too early or too late on real arrival patterns | Threshold configurable in `engine.py` |
| Single campus configuration | Generalization to other campuses not empirically tested | Three configs exist (vitap, toy_small, sample) |

## Section 4 — How to regenerate results

```bash
# Run experiment matrix (5 seeds pilot)
python scripts/run_all_experiments.py --seeds 5 --workers 2

# Generate summary tables
python scripts/generate_results_summary.py

# View prediction metrics
cat experiments/results/prediction_metrics.json

# View summary
cat experiments/results/summary_table.md
```

All results are reproducible given the same seed and configuration. The git commit hash is recorded in each run's manifest file under `runs/`.
